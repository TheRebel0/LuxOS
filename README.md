# LuxOS
An incredibly fast and lightweight OS for Raspberry Pi 5/500

#Only 47MB

LuxOS is a lightweight 47MB operating system built for the Raspberry Pi 500+ (Pi 5).

### What you need
- Raspberry Pi 500+
- SD Card (any size, FAT32)
- 2 minutes

### Install - No flashing needed
This OS uses a new system created by me called MDADIS (Modern Drag And Drop Install System)

1. Format SD card as **FAT32** and name it `LUXOS`
2. Download this repo from src.zip in latest release
3. Copy **everything inside to the root of your SD card
4. Put SD in Pi 5/500 and power on

That's it. No Balena Etcher, no IMG file.
